    Enum: ImagingInteroperabilityStandardEnum

    Standards and data models used to represent medical imaging metadata and to link images with clinical records, electronic health records and multimodal research datasets.

    URI: valuesets:ImagingInteroperabilityStandardEnum

    View in BioPortal

    Permissible Values

    Value Title Meaning Description Url
    DICOM DICOM Digital Imaging and Communications in Medicine (ISO 12052), the standard for storing, transmitting and managing medical imaging data https://www.dicomstandard.org/
    DICOMWEB DICOMweb RESTful web services for DICOM (QIDO-RS, WADO-RS, STOW-RS) defined in DICOM PS3.18 https://www.dicomstandard.org/using/dicomweb
    HL7_FHIR_IMAGINGSTUDY HL7 FHIR ImagingStudy FHIR resource representing a DICOM study and its series and instances, used to integrate imaging metadata into FHIR-based systems https://www.hl7.org/fhir/imagingstudy.html
    OMOP_CDM_IMAGING_EXTENSION OMOP CDM Imaging Extension OHDSI Observational Medical Outcomes Partnership Common Data Model extension for imaging-based observational research, used to link DICOM studies to clinical encounters https://github.com/OHDSI/OmopImaging
    IHE_PROFILES IHE integration profiles Integrating the Healthcare Enterprise profiles for image sharing and identifier management, such as XDS-I and PIX https://www.ihe.net/
    BIDS Brain Imaging Data Structure Community standard for organizing and describing neuroimaging datasets, commonly used after conversion from DICOM https://bids.neuroimaging.io/
    NIFTI NIfTI Neuroimaging Informatics Technology Initiative file format for volumetric images, the usual target of DICOM conversion in neuroimaging pipelines https://nifti.nimh.nih.gov/
